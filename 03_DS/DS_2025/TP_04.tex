\section*{Contexte}
\begin{wrapfigure}{r}{0.2\textwidth}
    \centering
    \includegraphics[width=\linewidth,trim=10 15 10 15, clip]{tx2-140.jpg}
\end{wrapfigure}
Vous travaillez sur l'intégration d'un robot Stäubli TX2~140 (6 axes) dans une cellule robotisée. 
L'objectif est de piloter le robot via un automate Schneider M340 utilisant le protocole Ethernet/IP.

Le réseau comporte les éléments suivants :
\begin{itemize}
    \item \textbf{Automate Schneider M340} Automate Maître. Adresses IP : \texttt{192.168.0.1/24}, \texttt{10.10.0.1}.
    \item \textbf{Automate Wago PFC200} Automate Esclave, connecté à l'IHM et au convoyeur. Adresse IP : \texttt{192.168.0.2/24}.
    \item \textbf{Contrôleur CS9 du robot Stäubli} Adresse IP : \texttt{192.168.0.10/24}.
    \item \textbf{Interface Homme Machine} Adresse IP : \texttt{192.168.0.12/24}.
    \item \textbf{PC de supervision} Adresse IP : \texttt{10.10.0.253}
\end{itemize}

Le protocole Ethernet/IP, dérivé du CIP, est utilisé pour la communication entre l'automate d'une part, l'automate Wago et le contrôleur CS9 d'autre part. L'automate Wago est équipé d'une carte réseau Ethernet/IP et de cartes d'entrées/sorties. Le contrôleur CS9 est équipé, entre autres, d'une carte réseau Ethernet/IP.
L'automate M340 est équipé d'un modules BMX NOC. 

Dans cette communication Ethernet/IP : 
\begin{itemize}
    \item La baie CS9 produit \textbf{148} octets de données et en consomme \textbf{124} octets.
    \item L'automate PFC200 produit \textbf{50} octets de données et en consomme \textbf{100} octets.
\end{itemize}

\section{Configuration de l'automate (20 minutes)}
\begin{UPSTIinfor}{Les coupleurs BMX NOC401.2}
    Ce coupleur utilise l'espace mémoire conventionnel de l'API (\%MWi) pour stocker :
    \begin{itemize}
        \item Les données d'entrée (\texttt{NOC\_ETHIP\_IN}) contenant 
        \begin{itemize}
            \item L'état de santé des connexions vers les équipements « Target » (\texttt{HEALTH\_BITS\_IN : ARRAY[0..31] OF BYTE})
            \item Les données de Production (INput) dont \textbf{la taille est définie par l'utilisateur}.
        \end{itemize}
        \item Les données de sortie (\texttt{NOC\_ETHIP\_OUT}) contenant
        \begin{itemize}
            \item La mise en service des connexions (\texttt{CONTROL\_BITS\_OUT : ARRAY[0..31] OF BYTE})
            \item Les données de Consommation (OUTput) dont \textbf{la taille est définie par l'utilisateur}.
        \end{itemize}
    \end{itemize}
    Chaque connexion est identifiée par un numéro de connexion (de 0 à 31). Le bit de santé de la connexion est stocké dans le tableau \texttt{HEALTH\_BITS\_IN} à l'indice correspondant au numéro de connexion. Par exemple, le bit de santé de la première connexion est stocké dans \texttt{HEALTH\_BITS\_IN[0].0}. Celui de la 10ème connexion est stockée dans \texttt{HEALTH\_BITS\_IN[1].1}. 
    Le même principe s'applique pour les bits de contrôle des connexions sortantes.
    \end{UPSTIinfor}

\section{Programmation et contrôle des mouvements (30 minutes)}
On propose de programmer le comportement de la cellule en suivant le Guide des Modes de Marche Automatisée (GEMMA). Dans cette étude, on se concentrera sur les modes 
\begin{itemize}
    \item A5 : Préparation pour la remise en route
    \item A6 : Mise en conditions initiales
\end{itemize}
\subsection{Le mode A5 : Préparation pour la remise en route}
On donne pour cahier des charges pour le mode A5 :
\begin{enumerate}
    \item Le robot doit se déplacer devant le détecteur de pièce. 
    \item Si une pièce est présente sur l'outil, le robot la dépose sur l'aire de stockage.
    \item Une fois le dépot effectué ou s'il n'y a pas de pièce, le robot se déplace en position de sécurité.
\end{enumerate}
Les coordonnées pour chacune des positions sont les suivantes :
\begin{center}
    \begin{tabular}{l|ccc|ccc}
        & X & Y & Z & RX & RY & RZ \\
        \hline
        Devant le détecteur & 100 & -400 & 150 & 0 & 0 & 0 \\
        \hline
        Stockage & 100 & -400 & 50 & 0 & 0 & 0 \\
        \hline
        Sécurité & 100 & -400 & 300 & 0 & 0 & 0 \\
    \end{tabular}
\end{center}
